Flutter Web Troubleshooting Guide

If you're experiencing issues with the Flutter web app, here are some common problems and solutions:

1. App Stuck at Loading Screen

Problem: The app shows a loading spinner but never loads.

Possible Solutions:

  • Try using the HTML renderer version instead of CanvasKit
  • Clear your browser cache and cookies
  • Try a different browser (Chrome works best with Flutter web)
  • Check if your browser has JavaScript enabled
  • Disable browser extensions that might be blocking scripts

2. WebGL Issues

Problem: CanvasKit requires WebGL, which might not be supported by your browser or hardware.

Solutions:

  • Check if WebGL is enabled in your browser by visiting https://get.webgl.org/
  • Update your graphics drivers
  • Use the HTML renderer version which doesn't require WebGL

3. CORS Errors

Problem: Cross-Origin Resource Sharing (CORS) errors can prevent assets from loading.

Solutions:

  • Check browser console (F12) for specific CORS errors
  • Make sure all resources are being loaded from secure origins (HTTPS)
  • If using custom assets or APIs, ensure they have proper CORS headers

4. Mobile Device Issues

Problem: The app may not work correctly on mobile devices.

Solutions:

  • Make sure you're using a recent mobile browser (Chrome or Safari)
  • For AR features, ensure your device supports ARCore (Android) or ARKit (iOS)
  • Try the HTML renderer version which is generally more compatible with mobile devices
